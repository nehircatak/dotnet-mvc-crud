# 📚 Education Management System (ASP.NET Core MVC)

A modern, secure, and full-stack web application built with **ASP.NET Core MVC**, **Entity Framework Core**, **SQLite**, **Bootstrap 5**, and **SweetAlert2**.

This project features complete **CRUD** functionality, real-time student/course search, dynamic notification toasts, interactive confirmation modals, and a robust **Cookie-based Authentication & Authorization** workflow.

---

## 🚀 Features

- **Authentication & Authorization:** Secure user registration, login, and logout flow using custom Cookie Authentication with protected routes (`[Authorize]`).
- **Complete CRUD Operations:** Create, Read, Update, and Delete education records with server-side and client-side validation.
- **Dynamic Search & Filtering:** Quick search bar filtering records by student name and topic.
- **Modern UI/UX:** Clean, responsive design using Bootstrap 5 cards and navigation bars.
- **Interactive Feedback:** Integrated SweetAlert2 for deletion confirmation modals and non-blocking toast notifications.
- **Database Integration:** SQLite database managed via EF Core Code-First migrations.

---

## 🛠️ Tech Stack

- **Backend:** C# / .NET 8 (or .NET 10) ASP.NET Core MVC
- **Database:** Entity Framework Core & SQLite
- **Frontend:** Razor Views, HTML5, CSS3, Bootstrap 5
- **Libraries:** SweetAlert2, jQuery Validation
